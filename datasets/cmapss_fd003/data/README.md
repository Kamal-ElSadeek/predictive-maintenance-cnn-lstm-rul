# C-MAPSS FD003 data

The notebooks expect the NASA C-MAPSS FD003 files `train_FD003.txt`, `test_FD003.txt`, and `RUL_FD003.txt`.

Raw data is not redistributed in this repository. Acquire it from an authorized NASA Prognostics Data Repository source, review its terms, and place the files in a local data directory. Update the historical notebook paths or use environment-relative paths before running.
